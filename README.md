**MSCS 634 – Deliverable 3: Classification, Clustering & Pattern Mining**
**Overview**
This repository contains Deliverable 3 for the course MSCS 634 – Advanced Big Data & Data Mining.The project applies supervised learning, unsupervised learning, and association rule mining techniques on a cleaned healthcare dataset. The goal is to build predictive models, analyze cluster structures, and extract meaningful patterns.

**Files Included:**
Deliverable3_Classification_Clustering_PatternMining.ipynb
Full implementation of classification models, clustering, hyperparameter tuning, and pattern mining.
cleaned_healthcare_data.csv
Preprocessed dataset used for all tasks.
README.md
Summary of project purpose, methods, and execution steps.

**Techniques Implemented:
Classification:**
Decision Tree Classifier
K-Nearest Neighbors (KNN)
Hyperparameter tuning with GridSearchCV
Evaluation metrics: Accuracy, F1-score, Confusion Matrix, ROC Curve

**Clustering:**
K-Means Clustering
Elbow Method for optimal K
Cluster visualization and interpretation

**Pattern Mining:**
Apriori Algorithm
Frequent Itemsets
Association Rule Mining (Support, Confidence, Lift)

**Key Learnings:**
Importance of encoding and scaling before model training
Impact of hyperparameters on performance
Interpreting cluster boundaries visually
Extracting insights from association rules
Differences between supervised and unsupervised learning

**How to Run**
Download or clone the repository.
Update the dataset path in the notebook.
Open the notebook in Jupyter Notebook or Google Colab.
Run the cells in order to reproduce results.
